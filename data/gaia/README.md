# Gaia data used by astrometry.ipynb

`epoch_astrometry.csv` and `sources.csv` contain the along-scan measurements (epoch astrometry) of Gaia-4,
Gaia BH3 and HD 114762 from the [Gaia DR4 pre-release](https://www.cosmos.esa.int/web/gaia/dr4-prerelease)
(June 2026), selected and reformatted by `tools/make_gaia_data.py` (which describes the columns).

(see https://www.cosmos.esa.int/web/gaia-users/license).

(https://www.cosmos.esa.int/gaia), processed by the Gaia Data Processing and Analysis Consortium (DPAC,
